# Notes de séance

Une note par séance. Copie [TEMPLATE.md](TEMPLATE.md) en
`AAAA-MM-JJ-type.md` (ex. `2026-09-15-muscu.md`).

## À quoi ça sert

- Garder une trace des charges réellement faites → alimente
  [tracking/1rm.md](../tracking/1rm.md) et le calcul des séances suivantes.
- Repérer les écarts avec le programme et les signaler au coach.
- Suivre douleurs, sommeil, forme → croiser avec la descente de poids.

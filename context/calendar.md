## Structure hebdo type (déjà fixée par Evan, ne pas replanifier)

| Jour | Séance | Horaire |
|------|--------|---------|
| Lundi | Musculation | à partir de 20h00 |
| Mardi | Judo | 17h30 – 19h00 |
| Mercredi | Musculation | à partir de 15h45 |
| Jeudi | Judo | 17h30 – 19h00 |
| Vendredi | Musculation | à partir de 16h00 |
| Samedi | Repos | — |
| Dimanche | Vélo longue durée | > 1h |

Récap : **3 muscu** (lun / mer / ven) · **2 judo** (mar / jeu) · **1 sortie
vélo longue** (dim). Cohérent avec les règles du coach (muscu ≥ 2/sem ; le
cardio du dimanche compense le volume de judo). Voir
[context/coach.md](coach.md).

**Compagne :** mêmes 3 séances de muscu/semaine mais placées **lundi / jeudi /
vendredi** (et non lundi/mercredi/vendredi comme Evan). 1RM et charges dans
[tracking/1rm.md](../tracking/1rm.md) §Compagne.

L'AI OS remplit le contenu de ces créneaux à partir de
[references/programme-cycle2.md](../references/programme-cycle2.md) ; il ne
déplace pas les créneaux.

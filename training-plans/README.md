# Fiches d'entraînement

Toutes les fiches et plannings transmis par le coach, rangés ici.

## Convention

- Un fichier par document reçu, nommé `AAAA-MM-JJ-sujet.ext`
  (ex. `2026-09-05-seminaire-1-programme.pdf`,
  `2026-09-14-cycle2-semaine5.png`).
- Les images/PDF bruts vont ici. La **transcription exploitable** (celle que
  l'AI OS lit) va dans `references/` — ex.
  [references/programme-cycle2.md](../references/programme-cycle2.md).
- Quand une fiche est remplacée par une nouvelle version, déplacer l'ancienne
  dans [archives/](../archives/).

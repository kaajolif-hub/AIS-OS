# Vidéos

Index des vidéos de judo : randoris, techniques, combats — entraînement et
compétition. Les fichiers vidéo eux-mêmes sont **lourds** : garde-les dans un
dossier local (Mac) ou iCloud et référence-les ici. Ne commite pas les vidéos.

## Convention de nommage

`AAAA-MM-JJ_contexte_adversaire-ou-theme.mp4`
- contexte : `rdr` (randori) · `tech` (technique) · `compet` · `entrainement`
- ex. `2026-09-15_rdr_lourd-gaucher.mp4`, `2026-10-02_compet_poule-selection.mp4`
